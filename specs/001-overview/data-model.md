# Data Model: 001-overview

PostgreSQL 15, managed with Drizzle migrations in `apps/web/db`. All timestamps are
`timestamptz` stored in UTC. Primary keys are UUIDs (`uuid`, generated by the database) unless
noted. Tables created by this feature are the minimum the shell needs; later features extend
them (noted per table).

## users

| Column | Type | Rules |
| --- | --- | --- |
| id | uuid PK | |
| full_name | text | required, 1–120 chars |
| username | text | required, unique (case-insensitive, `citext`), 3–120 chars |
| phone_e164 | text | required in 002; nullable for the installation Super Admin only if the installer omits it; format `+<country><number>` |
| email | citext | optional, unique when present |
| password_hash | text | bcrypt, cost ≥ 12 |
| status | enum `user_status` (`active`, `deactivated`) | default `active` |
| created_at, updated_at | timestamptz | |

Extended by 002 (remaining profile fields, warehouse assignments, temporary-password flag).

## user_roles

| Column | Type | Rules |
| --- | --- | --- |
| user_id | uuid FK → users | |
| role | enum `role` (`super_admin`, `admin`, `event_manager`, `store_manager`) | |
| granted_at | timestamptz | |

PK (`user_id`, `role`). A partial unique index on `role` where `role = 'super_admin'` enforces
exactly one Super Admin (FR-004).

## sessions

| Column | Type | Rules |
| --- | --- | --- |
| id | uuid PK | |
| token_hash | bytea | SHA-256 of the opaque token; unique |
| user_id | uuid FK → users | |
| client_platform | enum `client_platform` (`web`, `android`, `ios`) | |
| client_version | text | app version at sign-in |
| created_at | timestamptz | |
| last_seen_at | timestamptz | refreshed at most once per minute |
| expires_at | timestamptz | web: `last_seen_at + 60 min` (sliding); mobile: `created_at + 30 days` (fixed) |
| revoked_at | timestamptz | set on sign-out (and on deactivation, 002) |

A session is valid when `revoked_at IS NULL AND now() < expires_at` and the user is `active`.

## sign_in_attempts

| Column | Type | Rules |
| --- | --- | --- |
| id | bigserial PK | |
| username_attempted | citext | as typed |
| user_id | uuid FK → users, nullable | null when the username is unknown |
| network_address | inet | |
| succeeded | boolean | |
| attempted_at | timestamptz | indexed with `user_id` and with `network_address` |

Lockout rule: ≥ 5 rows with `succeeded = false` for the same `user_id` (or, for unknown names,
the same `network_address`) in the last 15 minutes → refuse until 15 minutes after the 5th.
Rows older than 90 days may be purged.

## audit_entries (append-only)

| Column | Type | Rules |
| --- | --- | --- |
| id | bigserial PK | |
| occurred_at | timestamptz | |
| actor_user_id | uuid FK → users, nullable | null for unknown-user failed sign-in or system actions |
| action | text | e.g. `auth.sign_in`, `auth.sign_in_failed`, `auth.sign_out`, `settings.mobile_version_changed` |
| entity_type, entity_id | text, text | nullable |
| before, after | jsonb | nullable; never contains passwords or tokens |
| client_platform, client_version | enum, text | |
| network_address | inet | |

The application database role has `INSERT, SELECT` only on this table (no `UPDATE`/`DELETE`),
enforcing constitution II/V. Retention ≥ 3 years (NFR-09).

## number_sequences

| Column | Type | Rules |
| --- | --- | --- |
| kind | enum `record_kind` (`event`, `damage_report`, `count_session`, `stock_transfer`, `item`) | |
| year | smallint | IST calendar year; `0` for kinds not numbered by year (`item`) |
| last_value | integer | ≥ 1 |

PK (`kind`, `year`). Issued inside the creating transaction (research R6). Formats
(`packages/shared/format/record-number.ts`):

| kind | Prefix | Digits (min) | Example |
| --- | --- | --- | --- |
| event | `EVT-YYYY-` | 4 | `EVT-2026-0001` |
| damage_report | `DMG-YYYY-` | 5 | `DMG-2026-00001` |
| count_session | `CNT-YYYY-` | 4 | `CNT-2026-0001` |
| stock_transfer | `TRF-YYYY-` | 4 | `TRF-2026-0001` |
| item | `ITM-` | 5 | `ITM-00001` |

Item code edits and the all-codes-ever uniqueness rule ship with the `items` / `item_codes`
tables in 003.

## Non-table reference data (code constants in `packages/shared`)

- **Module map** — `{ id, labelKey, roles[], apps[], shipped, deliveredIn }` per spec table.
  `shipped` is `true` only for `home`, `admin-status` (Super Admin status page and mobile
  versions) in 001.
- **Permissions** — `Permission` union (`admin.status.view`, `admin.mobile_versions.edit`, …) and
  `ROLE_PERMISSIONS: Record<Role, Permission[]>`; later features add their permissions here.

## Derived values

- **Menu** for a user = modules where `shipped` and `roles ∩ user.roles ≠ ∅` and the requesting
  app is in `apps`, de-duplicated, in module-map order.
- **Overall status** = `down` if database down; else `degraded` if any part down; else `ok`.
